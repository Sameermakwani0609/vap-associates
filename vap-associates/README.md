# VAP & Associates – Next.js site

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # production build
npm run start    # serve the production build
```

Where to edit things:
- `src/data/site.ts` – phone, email, team, services, news updates, compliance due dates
- `src/components/` – one file per section of the page
- `src/app/globals.css` – all styling (unchanged from the original HTML)
- `src/app/layout.tsx` – fonts and SEO title/description
- `public/` – put images / favicon here
